## Description of new features
- Score command shows player's score
- Added gold feature in Player.java
- Added 3 new rooms: Shed, House, Field
- feature/student-b-add-items: Adds items to the game such as the hatchet, potion, and a rare fish.
- feature/student-b-map-command: Allows the player to know where they are in the game.
- feature/student-b-reputation-system: Allows the player to gain reputation points.
